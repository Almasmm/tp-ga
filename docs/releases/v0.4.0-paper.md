Code and data of the article (tp-ga, work on version 0.4).

The attached archive `tp-ga-v0.4.0-paper-artifacts.zip` holds the tracked files of

* `paper_artifacts_v2/` contains the v0.4 instances, tuning, pilot and logs at this tag. The archive predates
  the commit that added the partial main-run results.
* `paper_artifacts_quick/` - the quick version of experiment v0.4 with every raw record, table and figure;
* `paper_artifacts_v3/` - the additional experiment v3 (amendments 8, 9 and 10): cycle mutation, one protocol
  for the linear problem up to 100x100, the fixed-charge problem with a MIP reference, tabu search and
  iterated local search as rivals, timing on one processor, effect sizes with intervals;
* `docs/v0.4/PREREGISTRATION.md` (the plan, its ten amendments and the records of what each rule gave),
  `experiments/` (every configuration), `CITATION.cff`, `.zenodo.json` and `LICENSE`.

The source archive of the tag holds the code that made them (`pip install -e ".[runner]"`); the commands are
in `README.md` (section "Computational experiment"), `paper_artifacts_v3/README.md` and `paper_artifacts_v2/README.md`.

Status of the results: the experiment of amendment 8 was planned before its code; amendments 9 and 10 were
written after earlier results were seen and are exploratory. The package version is `0.4.0.dev0`; this tag is
not a package release. The ten public fixed-charge instances of amendment 10 are not redistributed (their
source states no licence); the command `public` downloads them from a fixed commit and checks their SHA-256.
