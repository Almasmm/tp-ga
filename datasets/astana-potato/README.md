# Датасет «Поставки картофеля по Астане»

Набор v1 моделирует распределение картофеля между **24 складами и 324 точками** в шести районах Астаны. В полной задаче 7 776 направлений. В наборе 30 дневных задач, три стресс-сценария на основе первого дня и одна задача 8×40 для веб-API. Даты октября 2026 года обозначают дни симуляции. Остатки каждого дня заданы отдельно, перенос остатка между днями не моделируется.

Масштаб сети опирается на [публикацию акимата о 324 торговых павильонах](https://www.gov.kz/org/astana/press/article/details/247537). В публикации учтены объекты всех типов, из которых 129 относятся к овощам и фруктам. Число условных точек в каждом районе соответствует общему числу павильонов по данным акимата. Условные точки не соответствуют конкретным павильонам. [Сообщение о закупках картофеля](https://www.gov.kz/org/astana/press/news/details/921167?lang=ru) подтверждает практический контекст задачи. Контрактные объёмы не использовались как складские остатки.

Склады, точки, координаты, запасы, заявки и тарифы смоделированы. Координаты заданы на условной сетке в километрах и предназначены для схемы сети. Тариф складывается из условной стоимости обработки и переменной ставки за расчётное расстояние. Заявки учитывают размер точки, день недели и случайные колебания. В наборе есть дни с избытком, дефицитом и точным балансом. Данные подходят для проверки приложения и сравнения алгоритмов. Для оценки экономии конкретного оператора потребуются его выгрузки.

| Файл | Содержимое |
|---|---|
| manifest.json | Источники, единицы измерения, список задач, объёмы и связи стресс-сценариев с базовым днём. |
| network.json | Районы, условные координаты и порядок складов и точек в матрицах. Для pilot порядок задают отдельные списки идентификаторов в манифесте. |
| instances/day-01.json … day-30.json | Дневные задачи в формате tp-ga. Поля supply и demand заданы в кг, cost — в тенге за кг. Строки матрицы соответствуют складам, столбцы — точкам. |
| instances/stress-*.json | Варианты day-01: отключение склада с наибольшим доступным запасом, рост заявок в Сарыарке на 35% или рост тарифов на 30% для входящих межрайонных перевозок в Есиль и Нуру. |
| instances/pilot.json | 8 складов и 40 точек из полной сети. Запасы пересчитаны пропорционально, чтобы сбалансировать заявки этой подвыборки. |
| generate.py | Генератор на стандартной библиотеке Python с фиксированным seed 20261109. |

Из корня проекта с установленным tp-ga:

~~~powershell
python -m tpga solve datasets/astana-potato/instances/day-01.json --method lp
python -m tpga solve datasets/astana-potato/instances/day-01.json --method both --population 12 --generations 15 --seed 42
python datasets/astana-potato/generate.py --output C:\Temp\astana-potato
~~~

Полные задачи доступны в [веб-приложении](../../platform/README.md), через библиотеку и CLI. Для вызова прежнего маршрута API с произвольной матрицей подходит pilot.json с 320 направлениями.

В несбалансированных задачах библиотека добавляет фиктивный склад или точку с нулевой стоимостью. Поток от фиктивного склада означает неудовлетворённый спрос, поток к фиктивной точке — неиспользованный запас. Сравнивайте стоимость при одинаковом объёме реальных поставок. Для моделирования приоритетов при дефиците потребуются отдельные правила.
