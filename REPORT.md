### RQ2 — сравнение с NWC, LCM, VAM (`tables/T2_gap.csv`, `tables/T5_tests.csv`)

Средние отклонения классических методов (равномерные): VAM 3,69 / 15,38 / 24,47 / 24,51 / 33,98 / 36,48 %, LCM 10,55 / 33,69 / 49,72 / 54,78 / 73,34 / 94,17 %, NWC 107,25 … 2 043,56 % (от 5×5 до 100×100).

Основное сравнение по GA-rand (критерий Уилкоксона по медианам задач; p с поправкой Холма внутри группы «набор × размер», 7 сравнений):
* GA-rand лучше VAM на 5×5 (все 10 задач, r = −1, p = 0,031); на 10×10 различие не значимо (p = 0,131); на 20×20 … 100×100 хуже VAM на всех задачах (r = +1, p = 0,0137). По всем 80 синтетическим задачам: медианная разность +20,7 п.п., p_Holm(все строки) < 1e-4, r = 0,79.
* GA-rand против LCM: лучше на 5×5 и 10×10, не различим на 20×20 (p = 0,92), хуже с 30×30; по всем 80 задачам +5,7 п.п., p_Holm = 0,020.
* GA-rand лучше NWC и RS на всех размерах (кроме 5×5, где RS тоже почти всегда находит оптимум).
* GA-cost не хуже LCM/VAM **по построению** (их планы в начальной популяции, элитизм); фактически ни на одной из 80 синтетических задач не хуже VAM: медианная разность −7,4 п.п., r = −1, p_Holm < 1e-4.

Важно: на размер приходится 10 задач, минимальный точный p критерия Уилкоксона — 0,00195, поэтому при Холме по всем 63 строкам T5 ни одно сравнение внутри размера не опускается ниже 0,05 (p = 0,109), даже при одном знаке на всех 10 задачах. В T5 даны обе поправки; выбор — за автором статьи (записано в METHODS.md и LIMITATIONS.md).

### RQ3 — время (`tables/T3_time.csv`, `tables/T3_time_fit.csv`; фаза timing, P-ядра, схема питания «Сбалансированная»)

Медиана времени запуска: LP 0,0011 с (5×5) → 0,028 с (100×100); GA-rand 0,0085 → 26,9 с; GA-cost 0,0085 → 1,70 с. Время одного вызова декодера 0,43 → 36 мкс.
Аппроксимация t ≈ a·(m·n)^b по медианам 60 задач (25 ≤ m·n ≤ 10 000, без экстраполяции): LP b = 0,54 [0,49; 0,59], R² = 0,89; GA-rand b = 1,39 [1,32; 1,45]; GA-cost b = 0,91 [0,87; 0,96]; на один вызов декодера b ≈ 0,73–0,75. Показатель ГА во многом задан правилом бюджета и стагнацией; показатель ЛП на малых задачах — накладными расходами вызова `linprog`. Повторные запуски фазы timing дали те же стоимости, что основная фаза: 600 из 600.

### RQ4 — параметры (`tables/T4_factorial.csv`, `tables/T4_factorial_tests.csv`; 20×20 и 50×50, 30 запусков на ячейку)

Средний gap уменьшается с ростом популяции и вероятности мутации во всех четырёх группах; критерий Фридмана p < 1e-4 везде. 20×20, случайный старт: 239,84 % (P = 20, pm = 0,01) → 43,27 % (P = 200, pm = 0,2); с учётом стоимости: 19,91 → 6,52 %. 50×50: 855,00 → 179,97 % и 33,20 → 23,64 %. Старт с учётом стоимости лучше случайного во всех 160 ячейках (Уилкоксон, p < 1e-4, обе размерности). Лучшие ячейки — на краю сетки, т. е. сетка не охватывает оптимум параметров.

### Дополнительно: правило остановки (`tables/T2b_stopping.csv`)

Без стагнации (только бюджет) средний gap снижается: 50×50 GA-rand 227,4 → 177,5 %, GA-cost 25,8 → 21,9 %; 100×100 GA-rand 606,6 → 358,8 %, GA-cost 28,4 → 24,0 % (Уилкоксон p = 0,002 в каждой группе, n = 10); цена — время (GA-cost 100×100: 4,2 → 204 с). Результаты базовой конфигурации описывают ГА с правилом стагнации 200.

## 3. Достижимость оптимума (`paper_artifacts/reachability.json`)

1 000 случайных сбалансированных целочисленных задач (2…30 × 2…30, запасы ≤ 20 — чтобы вырожденность была частой): двойственный симплекс HiGHS дал целочисленную вершину во всех 1 000 случаях; перестановка из её опорного леса декодировалась ровно в эту вершину с оптимальной стоимостью в **1 000 из 1 000** случаев, включая **693** вырожденные вершины (меньше m+n−1 положительных перевозок). Это эмпирическая проверка на сгенерированных задачах, не доказательство.
